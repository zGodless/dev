 ###   1、代码替换
 ###   2、客户端与服务端端点配置:  \C137\src\Shared\Configuration\DeploymentEndpoints.json
```json
"Release": {
    "PortalListenUrls": "http://0.0.0.0:8080",
    "MortyPortalWebSocketUri": "wss://portal.yourdomain.com/ws/morty",
    "RickPortalAddress": "https://portal.yourdomain.com"
    }
```
###   3、Portal 生产 AllowedHosts:  \C137\src\Portal\appsettings.Production.json
```JSON
    "AllowedHosts": "portal.yourdomain.com"
```
###   4、虚拟机上的 portal-env: /etc/c137/portal-env
```Bash
    export AllowedHosts=portal.yourdomain.com
```
###   5、Docker 部署环境文件:  /opt/c137/deploy/docker/.env
```
    C137_PORTAL_SERVER_NAME=portal.yourdomain.com
    PORTAL_IMAGE=c137-portal:local
```
### SSL 证书路径
当前 Nginx 模板会根据 .env 里的域名拼接证书路径。
证书必须放在：
```
/etc/c137/certs/portal.yourdomain.com/fullchain.pem
/etc/c137/certs/portal.yourdomain.com/privkey.pem
```

## 构建发布/部署包
### 1、构建 Portal 发布目录
执行位置：
```
E:\zyl\code\C137
```
命令：
``` powershell
dotnet publish src\Portal\Portal.csproj `
  -c Release `
  --self-contained false `
  --no-restore `
  -o artifacts\portal-linux-x64 `
  -m:1 /nr:false
```
说明：
- -c Release：使用 Release 配置；
- --self-contained false：使用框架依赖部署，运行时由 Docker 基础镜像提供；
- -o artifacts\portal-linux-x64：输出到部署目录；
- -m:1 /nr:false：禁用并行 MSBuild 节点，符合项目构建约束；
- 不使用 -r linux-x64，因为 Portal 会连带触发多个 .NET Framework 4.6.2 插件项目构建，指定 Linux RID 会导致这些 net462 插件项目的 assets 文件不匹配。

Portal 是框架依赖模式，Linux 运行时由这个镜像提供：
```
FROM mcr.microsoft.com/dotnet/aspnet:10.0
```
### 2、生成数据库迁移脚本
命令：
```powershell
dotnet ef migrations script `
  --idempotent `
  --configuration Release `
  --no-build `
  --context PortalDbContext `
  --project src\Portal\Portal.csproj `
  --startup-project src\Portal\Portal.csproj `
  --output artifacts\portal-migrations.sql
```
生成：
```
E:\zyl\code\C137\artifacts\portal-migrations.sql
```
--idempotent 表示脚本是幂等迁移脚本，可重复执行，MySQL 会根据 __EFMigrationsHistory 判断哪些迁移已经应用。

### 4、在虚拟机上如何使用这个包
上传后在 Ubuntu 上：
```bash
tar -xzf /tmp/c137-deploy-bundle.tar.gz -C /opt/c137/build

cd /opt/c137/build

docker build \
  -f deploy/docker/Portal.Dockerfile \
  -t c137-portal:local .
```
Portal.Dockerfile 里的关键行是：
```dockerfile
COPY artifacts/portal-linux-x64/ .
```
所以包里的 artifacts/portal-linux-x64 是构建 Docker 镜像的必需输入。
