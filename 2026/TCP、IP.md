# OSI 7层网络模型
    应用层、表示层、会话层、传输层、网络层、数据链路层、物理层
 
 ## 各协议在分层模型中的位置
    网络层              IP协议      
    传输层              TCP协议、UDP协议     
    应用层、表示层       HTTP协议、HTML协议、FTP协议、SMTP协议、SSH协议(远程登录服务)等

# TCP
    精髓：开放性和实用性
    
    有连接（区别于UDP的无连接）
